Bike Sales Data Analysis

Objective
  In this project it focuses on analyzing bike sales and using Python. The main objective is to understand the dataset about sales performance, product categories profit through visualisation

Tools
- Python
- Pandas
- Matplotilb
- Seaborn

DataSet
  the data set contains sales information using:
- Customer age and gender
- Country
- Product category
- Unit cost and unit price
- Profit, cost, revenue
- sales date and year

Transformation
- Checked and handled missing values
- cleaned column names
- converted financial columns into numeric data types
- created additional columns such as Model, Colour, Serial, and Profit Margin
- demonstrated the graph and compared the sales information

Conclusion
  this project demonstrates how python libraries can be used to clean transform, analyze and visualize bike sales information to generate meaningful business insights.
